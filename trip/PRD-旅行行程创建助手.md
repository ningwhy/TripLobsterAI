# 旅行行程创建助手 PRD（产品需求文档）

---

## 一、项目概述

### 1.1 项目名称
**行程规划助手**（TripPlanner Pro）

### 1.2 产品类型
Web端 / 移动端Web应用（H5）/ 小程序（后续扩展）

### 1.3 核心功能定位
一款智能旅行行程规划工具，帮助用户创建、编辑和管理旅行行程，支持自驾和公共交通两种出行方案，自动计算行程距离和时间，并提供一站式票务预订服务。

### 1.4 产品形态
用户通过网页或移动端访问产品，上传行程页面截图或手动输入停留地点，系统自动计算行程路线、时间、距离，并支持票务预订。

---

## 二、MVP（最小可行产品）范围

### 2.1 MVP核心功能清单

| 序号 | 功能模块 | 功能描述 | 优先级 |
|------|----------|----------|--------|
| 1 | 行程创建 | 用户可手动创建行程，添加停留地点 | P0 |
| 2 | 地点管理 | 支持5类地点：酒店、饭店、景点、购物点、其他 | P0 |
| 3 | 地图计算 | 调用百度/高德地图API计算两点间距离和时间 | P0 |
| 4 | 自驾方案 | 显示自驾时间和距离 | P0 |
| 5 | 公共交通方案 | 支持高铁/飞机+打车/地铁/公交，显示时间和距离 | P0 |
| 6 | 交通枢纽自动添加 | 自动添加机场、高铁站、公交站等交通枢纽 | P0 |
| 7 | OTA票务预订 | 对接携程/飞猪/美团接口（预留接口） | P1 |

### 2.2 MVP边界说明
- MVP阶段仅支持手动输入地点，暂不支持OCR识别截图
- MVP阶段仅对接地图SDK计算距离时间，暂不实现实际票务预订功能
- MVP阶段仅支持单次行程创建，暂不支持行程分享/导出

## 三、目标用户

### 3.1 主要用户画像

| 用户类型 | 特征描述 | 核心需求 |
|----------|----------|----------|
| 自由行游客 | 追求个性化行程安排的自助旅行者 | 灵活规划路线、比较不同交通方案 |
| 家庭出游 | 携带老人小孩的家庭旅行者 | 便捷添加多个停留点、合理安排时间 |
| 出差兼旅游 | 商务出行兼顾旅游的用户 | 快速创建行程、查看交通距离 |
| 学生群体 | 预算有限、追求性价比的年轻用户 | 比较自驾vs公共交通成本 |

### 3.2 用户痛点
1. 手动规划行程繁琐，需要逐个查询各地点间距离
2. 不清楚自驾和公共交通的时间和成本差异
3. 需要在多个App之间切换预订机票、火车票、景点门票
4. 不知道如何合理安排交通枢纽中转

## 四、功能详细描述

### 4.1 行程创建功能

#### 4.1.1 基本信息设置
- 行程名称（必填）
- 行程开始日期（必填）
- 行程结束日期（必填）
- 出行人数（选填）

#### 4.1.2 停留地点管理
**地点类型（共5类）：**

| 类型 | 图标 | 说明 |
|------|------|------|
| 酒店 | 🏨 | 住宿地点 |
| 饭店 | 🍽️ | 餐饮地点 |
| 景点 | 🏞️ | 旅游景点、博物馆等 |
| 购物点 | 🛍️ | 商场、市场、免税店等 |
| 其他 | 📍 | 临时停留点、加油站、服务区等 |
| 交通枢纽 | 🚉 | 机场、高铁站、公交站、汽车站、港口（自动添加） |

**地点信息字段：**
- 地点名称（必填）
- 地点类型（必选）
- 地址（必填，支持地图搜索自动补全）
- 到达日期（必填）
- 停留时长（选填，默认2小时）
- 备注（选填）

**交互说明：**
- 用户点击"添加地点"按钮，弹出地点添加表单
- 支持拖拽排序调整地点先后顺序
- 支持删除已添加的地点

### 4.2 地图计算功能

#### 4.2.1 地图SDK集成
- 集成百度地图SDK或高德地图SDK（可配置）
- 支持地图展示、POI搜索、路径规划

#### 4.2.2 距离时间计算
- 自动计算相邻两个地点之间的直线距离和驾驶距离
- 返回预计驾车时间（基于实时路况）
- 计算结果缓存，减少API调用

**计算逻辑：**
```
for i in range(len(locations) - 1):
    distance = maps_api.get_distance(locations[i], locations[i+1])
    duration = maps_api.get_duration(locations[i], locations[i+1])
    add_route(distance, duration)
```

### 4.3 出行方案选择

#### 4.3.1 自驾方案
- 显示每段行程的自驾时间（小时/分钟）
- 显示每段行程的自驾距离（公里）
- 显示总自驾时间和总距离
- 考虑路况因素的预计到达时间

#### 4.3.2 公共交通方案

**支持的交通方式组合：**

| 主交通方式 | 接驳方式 | 说明 |
|------------|----------|------|
| 飞机 | 打车/地铁/公交 | 适用于长距离跨省出行 |
| 高铁 | 打车/地铁/公交 | 适用于中长距离出行 |
| 普通火车 | 打车/地铁/公交 | 适用于中短距离出行 |
| 汽车/大巴 | 打车/公交 | 适用于短距离或偏远地区 |
| 渡轮 | 打车/公交 | 适用于沿海/沿江城市 |

**交通枢纽自动添加规则：**
- 选择飞机：自动在出发地和目的地添加最近机场
- 选择高铁：自动在出发地和目的地添加最近高铁站
- 选择火车：自动添加火车站
- 选择汽车：自动添加汽车站
- 选择渡轮：自动添加港口

**公共交通计算逻辑：**
1. 根据出发地和目的地距离自动推荐主交通方式
2. 计算主交通方式的行程时间
3. 计算从地点到交通枢纽的接驳时间
4. 汇总显示总行程时间

### 4.4 票务预订功能（预留接口）

#### 4.4.1 OTA接口对接
预留以下OTA平台接口，实际预订功能在后续版本实现：

| OTA平台 | 支持业务 | 接口状态 |
|---------|----------|----------|
| 携程 | 机票、火车票、酒店、景点门票 | 预留接口 |
| 飞猪 | 机票、火车票、酒店、景点门票 | 预留接口 |
| 美团 | 酒店、景点门票、餐饮 | 预留接口 |

#### 4.4.2 预订信息展示
- 显示航班号/车次
- 显示出发时间、到达时间
- 显示票价（如果有接口）
- 提供预订跳转链接

### 4.5 行程展示

#### 4.5.1 行程概览
- 行程时间轴展示
- 每日行程安排
- 总距离、总时间统计

#### 4.5.2 地图可视化
- 在地图上标注所有地点
- 显示路线连接
- 支持切换自驾/公共交通视图

## 五、非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 3秒 |
| 地图计算响应时间 | < 2秒/每次计算 |
| 地点搜索响应时间 | < 500ms |
| 支持的最大地点数 | 50个/行程 |

### 5.2 兼容性要求

| 平台 | 最低版本要求 |
|------|--------------|
| iOS Safari | iOS 12+ |
| Android Chrome | Android 7.0+ |
| 微信小程序 | 支持 |
| PC浏览器 | Chrome 80+ / Edge 80+ / Firefox 75+ / Safari 13+ |

### 5.3 地图SDK要求

| 厂商 | SDK版本 | API要求 |
|------|---------|---------|
| 高德地图 | V2.0+ | Web JS API |
| 百度地图 | V3.0+ | Web JS API |

### 5.4 数据安全要求
- 用户行程数据本地存储或云端加密存储
- 地图API Key安全存储，不暴露在前端
- 遵守相关隐私政策

### 5.5 国际化支持
- MVP阶段仅支持中文
- 后续版本支持多语言（英文、日文、韩文）
