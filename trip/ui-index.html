可操作的交互

  • 创建行程：点选项卡切换选中 → 底部按钮在四步间前进/后退 → 第 4 步生成行程进入详情页。
  • 行程详情：点 Day 1/2/3 平滑滚动到对应日期分组；手动滚动时高亮自动跟随当前分组（程序化滚动期间抑制抖动）。
  • 旅行相册：点「管理」进入多选 → 点格子切换勾选 → 底部已选计数实时更新 → 点照片进入深色看图。
  • 交通选择：点圆形图标切换出行方式 → 点车次行变为浅紫选中态 → 底部确认给反馈。
  • 各页底部都有互跳链接；所有页面零外部依赖，可直接离线打开。
