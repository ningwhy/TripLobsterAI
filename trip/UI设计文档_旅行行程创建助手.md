# 旅行行程创建助手 App UI 设计文档

## 1. 项目概述

### 1.1 项目信息
- **项目名称**：旅行行程创建助手 (Trip Planner)
- **项目类型**：Flutter 移动端 App (iOS/Android)
- **核心功能**：帮助自由行游客创建和管理旅行行程，包含地点管理、路线规划、出行方案选择等功能
- **目标用户**：自由行游客

### 1.2 设计目标
- 简洁现代的旅行类App设计风格
- 直观易用的行程创建体验
- 清晰的地点信息展示
- 便捷的出行方案对比

## 3. 组件设计

### 3.1 行程信息头部组件 (TripHeader)

#### 3.1.1 行程名称输入框
- **类型**：TextField / TextFormField
- **样式**：
  - 背景：白色 (#FFFFFF)
  - 圆角：12px
  - 边框：1px 灰色 (#E0E0E0)
  - 内边距：16px 水平，14px 垂直
  - 字体：16px，黑色 (#333333)
  - 占位符："请输入行程名称"，灰色 (#999999)
- **交互**：点击进入编辑模式，显示光标键盘

#### 3.1.2 日期选择器
- **类型**：自定义点击区域 + DateRangePicker
- **样式**：
  - 背景：浅灰色背景 (#F5F5F5)
  - 圆角：8px
  - 图标：日历图标，灰色 (#666666)
  - 文字："02月21日 - 02月23日"，14px，黑色 (#333333)
- **交互**：点击弹出 Flutter 内置 DateRangePicker 或自定义日期选择弹窗

#### 3.1.3 出行人数选择器
- **类型**：自定义点击区域 + 数字选择器
- **样式**：
  - 背景：浅灰色背景 (#F5F5F5)
  - 圆角：8px
  - 图标：用户图标，灰色 (#666666)
  - 文字："2人"，14px，黑色 (#333333)
- **交互**：点击弹出人数选择底部弹窗（1-10人）

## 6. 功能模块详细设计

### 6.1 行程信息模块

#### 6.1.1 行程名称输入
- 输入框支持最多30个字符
- 实时校验，非空验证
- 失焦后保存到状态管理

#### 6.1.2 日期范围选择
- 支持选择开始日期和结束日期
- 开始日期不能晚于结束日期
- 行程最长支持30天
- 选择后自动计算行程天数

#### 6.1.3 出行人数设置
- 支持1-10人选择
- 默认值为2人

### 6.2 地点管理模块

#### 6.2.1 添加地点
- 点击"+"按钮弹出添加地点页面
- 支持搜索添加已有POI
- 支持手动输入新建地点
- 选择地点类型（5+1类）
- 关联日期（哪一天visit）

#### 6.2.2 地点类型
| 类型 | 图标 | 标签颜色 |
|------|------|----------|
| 交通枢纽 | ✈️ | #4A90D9 |
| 酒店 | 🏨 | #9B59B6 |
| 景点 | 🎫 | #E74C3C |
| 餐厅 | 🍽️ | #F39C12 |
| 购物 | 🛍️ | #2ECC71 |
| 其他 | 📍 | #95A5A6 |

#### 6.2.3 交通枢纽自动添加逻辑
- 当用户切换到"公共交通"方案时
- 系统自动分析起终点
- 自动插入交通枢纽（机场/火车站）
- 交通枢纽标记为系统自动添加，可删除

### 6.3 地图计算模块

#### 6.3.1 高德/百度地图SDK集成
- 计算两点间直线距离（可选）
- 计算两点间驾车路线距离和时间
- 计算两点间公共交通时间（需要路径规划）

#### 6.3.2 距离/时间展示格式
- 距离 < 1km：显示"XX米"
- 距离 >= 1km：显示"X.X公里"
- 时间 < 60分钟：显示"XX分钟"
- 时间 >= 60分钟：显示"X小时XX分钟"

### 6.4 出行方案模块

#### 6.4.1 自驾方案
- 基于起终点调用地图SDK
- 返回总距离和总驾车时间
- 显示途经点路线
- 支持查看详细路线

#### 6.4.2 公共交通方案
- 自动识别需要的长途交通（高铁/飞机）
- 自动添加交通枢纽
- 显示每段交通方式和接驳方式
- 整合计算总耗时
- 支持查看各段详情

### 6.5 OTA跳转模块

#### 6.5.1 支持的平台
- 携程
- 飞猪
- 去哪儿
- 马蜂窝

#### 6.5.2 跳转逻辑
- 点击"去预订"弹出平台选择
- 选择平台后跳转对应H5页面或App
- 传递地点关键词用于搜索
